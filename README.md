# CARE New Starter Form

Online New Starter Form for Creative Appeal Real Estate (CARE) employees.

Live at: https://carerealestate.github.io/care-onboarding/

Nothing is stored or sent by this page. Answers stay in the starter's browser until they create their PDF pack and send it to CARE.
To change the secure upload link or email, edit the two SETTINGS lines near the bottom of `index.html`.
